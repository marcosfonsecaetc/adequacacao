Sistema Adequação (ETC)
Projeto PHP para gestão de inclusão escolar com plano AEE (acompanhamento de alunos com necessidades educacionais especiais).

Stack
PHP + MySQL/MariaDB + PDO + Bootstrap + XAMPP

Funcionalidades

cadastro/edição/listagem de alunos
gestão de dados pedagógicos, saúde e plano de adequação
upload/visualização de foto de aluno
geração de perfil/relatório por turma
controle por papéis (admin, gestor, aee, professor, apoio, etc)
